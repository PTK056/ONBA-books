# ONBA Books

Commercial version of the Casa ONBA Control Room: a finance & operations dashboard
for short-term-rental villas, sold to owners and property managers.

Casa ONBA is "client #0". Nothing in this folder reads or writes the Casa ONBA
Airtable base.

- `docs/` — scoping, product spec, pricing, market notes
- `app/`  — the application (not started)
